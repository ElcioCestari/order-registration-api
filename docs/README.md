## ADRs (Architecture Decision Records)

Um ADR registra **uma** decisão de arquitetura: o contexto, a decisão, as alternativas
consideradas e as consequências. Uma decisão aceita não é editada depois; se ela mudar,
um novo ADR a substitui e o antigo passa a ter o status "Substituída por ADR-XXXX".
